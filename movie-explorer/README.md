# Movie Explorer

## Objective

Build a movie catalog application that consumes a public API (TMDB API) and allows users to search, filter, view details, and mark favorites with local persistence. [Here is the link](https://developer.themoviedb.org/docs/getting-started).

## Technical Requirements

- React 18+ (with Hooks)
- TypeScript
- React Router
- State Management: Zustand or Redux Toolkit
- Tailwind or CSS Modules
- Vite or Next.js
- Testing: Vitest / Jest + React Testing Library

## Functional Requirements

- Dynamic search with debounce and error handling
- Movie listing with responsive grid and infinite scroll
- Details page with caching and optimized fetching
- Favorites persisted in localStorage or IndexedDB

## Extras

- Unit and integration testing
- Modular architecture with technical justification
- Error Boundaries and Suspense
- Custom hooks with caching

## Note

Design is flexible. You may use custom styles or a library like Tailwind. Likewise, the layout is up to you, as mentioned in the requirements. You can create a Netflix-style grid layout or use pagination in a list/table format.
